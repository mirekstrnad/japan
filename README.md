# Japonsko – přehled uložených IG reels

Interaktivní průvodce vygenerovaný z Instagram kolekce „Japonsko":

- **Plán podle měst** (jen vybraná místa / všechny reely podle měst) s filtrem podle kategorií
- Hodnocení každého reelu + reálná veřejná hodnocení (Google / Tabelog / Tripadvisor) u ověřených míst
- Odkaz na každý reel a na Google Maps

Otevři **index.html** (nebo přes GitHub Pages).
